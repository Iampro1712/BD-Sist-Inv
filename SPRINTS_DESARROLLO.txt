METODOLOGÍA
  El desarrollo de Inventrix se llevó a cabo siguiendo un enfoque iterativo e
  incremental. Cada sprint entregó funcionalidades completas y desplegables,
  priorizando los módulos core del sistema antes de incorporar mejoras de
  experiencia de usuario y características avanzadas.

SPRINT 2 — ÓRDENES DE COMPRA, VENTAS Y MOVIMIENTOS DE INVENTARIO
Período: Diciembre 2025
Estado: COMPLETADO
================================================================================

OBJETIVO
  Implementar el ciclo completo de compras y ventas con actualización automática
  de stock e historial de movimientos.

TAREAS COMPLETADAS
  [x] Módulo de Órdenes de Compra (RF-10)
        - Modelo de orden con proveedor, estado (Pendiente/Recibida/Cancelada)
        - Modelo de detalle de orden con múltiples ítems, cantidad y precio
        - Cálculo automático de subtotales, impuestos y totales
        - Actualización automática de stock al marcar orden como Recibida
        - Serializers con lógica de negocio personalizada

  [x] Módulo de Órdenes de Venta (RF-11)
        - Modelo de orden con cliente, estado y múltiples ítems
        - Decremento automático de stock al registrar venta
        - Validación de stock suficiente antes de confirmar venta
        - Validación de fecha: no se permiten fechas futuras
        - Cálculo de subtotales, descuentos y totales

  [x] Módulo de Movimientos de Inventario (RF-12)
        - Registro automático de movimientos ante cada cambio de stock
        - Tipos de movimiento: entrada, salida, ajuste
        - Referencia al origen del cambio (orden de compra, venta)
        - Historial de solo consulta (inmutable)

  [x] Mejoras a serializers y vistas de la API
        - Lógica personalizada en serializers de compra y venta
        - Comentarios de desarrollo para facilitar mantenimiento

ENTREGABLES
  - Ciclo de compras completo: crear orden → recibir mercadería → actualizar stock
  - Ciclo de ventas completo: crear venta → validar stock → decrementar inventario
  - Historial de movimientos de inventario con trazabilidad por origen

COMMITS ASOCIADOS
  dad5a1a - feat(api): Enhance purchase and sales order serializers with custom logic
  9fbb742 - chore(api): Add development marker comments to serializers and views

SPRINT 3 — BITÁCORA DE SERVICIOS, MOTOS Y ALMACENAMIENTO EN LA NUBE
Período: Marzo 2026 (semana del 11)
Estado: COMPLETADO
================================================================================

OBJETIVO
  Implementar el sistema especializado de bitácora de servicios para motos con
  soporte fotográfico en Cloudflare R2.

TAREAS COMPLETADAS
  [x] Módulo de Motos (RF-06)
        - Modelo: marca, modelo, año, placa de circulación
        - Asociación moto → cliente propietario
        - Filtrado de motos por cliente

  [x] Módulo de Servicios de Moto (RF-07, RF-08)
        - Catálogo de servicios estándar con nombre y precio de mano de obra
        - Registro de servicios por moto: tipo, costo, descripción y fecha
        - Historial de servicios por moto y por cliente

  [x] Bitácora de Servicios — 4 Módulos (RF-09)
        - Modelo de bitácora con 4 etapas secuenciales:
            1. Recepción: estado inicial, nivel de combustible, daños
               preexistentes
            2. Diagnóstico: problemas identificados con evidencia fotográfica
            3. Reparación: trabajos realizados, técnico responsable, fotos
               de progreso
            4. Entrega: checklist de finalización y confirmación al cliente
        - Soporte de notas, técnico responsable y múltiples fotos por etapa
        - Vista combinada servicio + bitácora en la API

  [x] Integración con Cloudflare R2 (RNF-04.3)
        - Almacenamiento de fotografías de bitácora en R2
        - URLs referenciadas en campos JSONB de PostgreSQL
        - Compatible con API S3 para portabilidad futura

  [x] Despliegue y configuración
        - Actualización de VITE_API_URL al nuevo endpoint de producción
        - Actualización de react-router-dom a versión 7.13.1
        - Renovación de caché en Vercel

ENTREGABLES
  - Sistema de bitácora completo para documentar el ciclo de vida de un
    servicio de moto desde recepción hasta entrega
  - Almacenamiento de imágenes en Cloudflare R2 operativo
  - API de bitácora integrada con el módulo de servicios y clientes
